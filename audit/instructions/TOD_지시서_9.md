## 1. Part A — L2 사후 관문 (원 논문의 8시간 수면 기준)

원 논문(보고서 8 §3.1 인용)에 따르면 `relclocktime`은 습관적 수면 시작 기준이고, 습관적 수면은 8시간이다. 그러므로 습관적 기상 기준 시각은 다음과 같다.

`wake_corr = (relclocktime − 8) mod 24`

- **사후 관문:** period 1에서 PER1과 PER3의 정점을 `wake_corr` 축으로 다시 낸다. 사전등록 L2 창(정점 ≥ 18 또는 ≤ 2)에 들어가는지 적는다. LRT p는 축을 옮겨도 같다는 것을 표에 적는다.
- **유전자 10개:** 시계 유전자 10개(ARNTL은 BMAL1 별칭)의 정점을 `wake_corr` 축으로 낸다. GSE39445 정점(hours_awake 축)과의 부호 있는 차이, 원형 평균, 원형 SD를 낸다 (지시서 8과 같은 식).
- **시계:** 주 시계 3개와 보조 시계 2개의 정점을 `wake_corr` 축으로 낸다 (참고용).

## 2. Part B — 편향 시뮬레이션

목적: 확인된 효과 크기로, 채혈 시각 차이가 흔한 연구 설계에서 가짜 변화와 위양성을 얼마나 만드는지 계산한다. 시계는 주 시계 3개와 보조 시계 2개다.

### 2.1 매개변수 (두 시나리오)

| 시나리오 | 리듬 f(t) | 개인 내 SD | 사람 간 SD |
|---|---|---|---|
| lab | L1 Day 1 모형 M의 β_cos, β_sin | L1 σ (REML 잔차 SD) | L1 영모형(임의절편만)의 REML 절편 SD σ_u |
| free-living | f(t) = A·cos(2π(t − φ̄)/24). φ̄는 F1 값이고, A는 f(8) − f(20)이 L3 관측 mean Δ가 되도록 정한다. L3 mean Δ의 95% 구간 상한으로 정한 A로 "상한" 시나리오를 더한다 | 차이의 SD = L3 `sd_delta` | 단일 측정 SD = L3 아침 점수의 SD |

- free-living의 코사인 모양과 φ̄는 가정이다. 표에 적는다.
- 매개변수 표를 `results/stage9/sim_parameters.tsv`로 낸다.

### 2.2 설계 1 — 단일군 사전·사후 (참 효과 없음)
- 사전 채혈은 08:00, 사후 채혈은 08:00 + s. s = 0, 1, 2, 3, 4, 6, 8, 12시간.
- 가짜 평균 변화: b(s) = f(8 + s) − f(8). 시계 단위로 내고(RNAAgeCalc는 "년"으로 표시), 사람 간 총 SD 대비 비율로도 낸다. 총 SD는 lab에서는 sqrt(σ² + σ_u²), free-living에서는 단일 측정 SD다.
- 위양성률: 대응 t 검정, 양측 α = 0.05, n = 20, 50, 100, 200. 비중심 t로 계산하고 ncp = b / SD_diff × sqrt(n)이다. SD_diff는 lab에서 sqrt(2)·σ, free-living에서 L3 `sd_delta`다.
- 시계마다 "n = 100에서 위양성률이 10%를 넘는 가장 작은 s"를 낸다.
- **몬테카를로 확인:** lab, n = 50, s = 3에서 모형 M(임의절편 + 잔차)으로 2000회 생성해 위양성률을 해석적 값과 비교한다. 시드는 20261019.

### 2.3 설계 2 — 두 군 병렬 비교 (참 효과 없음)
- A군은 08:00, B군은 08:00 + s에 채혈한다. s는 2.2와 같다.
- 군당 n = 25, 50, 100, 200. 가짜 군 간 차이는 b(s)다.
- 위양성률: 두 표본 t 검정(같은 분산), 양측 α = 0.05. SD는 총 SD다.

### 2.4 설계 3 — 통제되지 않은 채혈 시각 (편향 없음, 잡음 증가)
- lab 시나리오만 한다. 사전·사후 채혈 시각을 각각 독립적으로 Uniform(08:00, 08:00 + W)에서 뽑는다. W = 0, 2, 4, 8시간.
- 참 효과 δ = 0.3 × sqrt(2) × σ (사후에 더함). n = 50.
- 몬테카를로 2000회(시드 20261019)로 대응 t 검정력과 평균 추정 편향을 낸다.

## 3. Part C — 완화

### 3.1 세포 구성 보정 (코사이너 자료)
- 자료: GSE39445, GSE56931, GSE113883, L1 Day 1. 시계 5개.
- MCPcounter 8개 점수를 **참가자 안에서 중심화**(참가자 평균을 뺌)해 모형 M에 고정 효과로 넣는다. 그러면 사람 간 구성 차이(나이와 관련될 수 있음)는 건드리지 않는다.
- 보정 전후의 2A, R2_within, LRT p, 정점을 내고, 2A_보정후 / 2A_보정전 비율을 낸다.
- L1은 조성 점수가 비유한인 샘플을 두 모형에서 함께 뺀다 (D9와 같은 규칙).

### 3.2 세포 구성 보정 (L3)
- 시계마다 Δclock(아침 − 저녁)을 Δcomposition(MCPcounter 8개의 아침 − 저녁)에 절편과 함께 회귀한다. 절편이 보정된 mean Δ이고, 95% 구간과 p를 낸다.
- 같은 표에 보정 전 mean Δ와 시각 보정 후 잔차(H5의 mean Δ − c, 해당 시계만)를 나란히 둔다.

### 3.3 나이 연관 보존 확인 (L3)
- 보정 점수: 아침 = 점수 − β̂ᵀ(Δcomposition / 2), 저녁 = 점수 + β̂ᵀ(Δcomposition / 2). β̂는 3.2의 회귀 계수다. 사람 평균은 바뀌지 않는다.
- 시계마다 나이와의 Pearson r을 낸다: 아침(보정 전·후), 저녁(보정 전·후), 사람 평균.

### 3.4 요약 표
- 시계 × 자료: 보정 전 효과 → 구성 보정 후 효과 → (L3만) 시각 보정 후 효과
