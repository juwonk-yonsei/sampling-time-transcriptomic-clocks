## 2. Part B — 사후 분석

### 2.1 L2 시각 기준 보정
- 원 논문(Kervezee et al., J Biol Rhythms, PMID 30621487)에서 참가자의 습관적 수면 시작 시각(평균과 범위)을 찾아 원문 인용한다. 찾지 못하면 "확인 못 함"으로 적고 이 절의 시각 변환을 하지 않는다.
- 찾았으면:
  - 참가자별 값이 있으면 참가자별로, 없으면 평균으로 `relclocktime`을 근사 벽시계 시각으로 바꾼다: `clock_approx = (relclocktime + 수면 시작 시각) mod 24`
  - period 1에서 PER1, PER3의 정점을 이 축으로 다시 내고, 사전등록 L1 관문 창(04–12시)에 들어가는지 적는다 ("사후 관문").
  - 주 시계 3개의 정점을 같은 축으로 내고, 개발 φ̄(F1)와의 원형 거리를 낸다.

### 2.2 자료 전체 효과 요약 (기술, 합치지 않음)
- 시계 5개 × 자료 6개(GSE39445, GSE56931, GSE113883, L1, L2(사후), L3)의 표를 만든다. 열:
  - 역할(개발, 확인, 사후)
  - 코사이너 자료: 2A/σ [구간], R2_within [구간], 정점 [구간], LRT p
  - L3: d [95% 구간], mean Δ [구간], p
- 메타분석으로 합치지 않는다.

### 2.3 L3 관측 효과와 예측 비교
- 시계마다 관측 d [95% 구간]과 개발 예측 d_exp(중앙값과 GSE113883 값, F2)를 나란히 둔다.
- 관측 d에서의 검정력(쌍 58개, 양측 α = 0.05)을 참고값으로 낸다.

### 2.4 L1 모듈 결과의 D11 판
- 표 F3의 결과 8개를 D11(참가자 평균 대체) 점수로 모형 M에 맞춘다. 사전등록 S4의 기준(LRT p < 0.05이고 정점이 φ̄ ±3시간 안)으로 "사후 확인" 여부를 적는다.
- 각 성분이 세 판(동결, D2, D11)에서 실제로 쓴 특징 수를 함께 적는다.
