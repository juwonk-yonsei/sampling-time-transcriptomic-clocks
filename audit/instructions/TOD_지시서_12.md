## 2. 수정

1. **Fig. 2**
   - 각 행 위에 행 이름을 9 pt 굵게, 왼쪽 정렬로 둔다: "GSE113883 (development)", "GSE48113 Day 1 (confirmation)".
   - 패널 머리글은 두 줄로 쓴다. 첫 줄은 시계 이름이고, 둘째 줄은 "p = …; peak … h"다.
   - 위, 왼쪽, 오른쪽 여백을 늘린다. 모든 글자가 쪽 경계에서 1 mm 이상 안쪽에 있어야 한다.
2. **Fig. 3b, Fig. 4b, Fig. S1b**
   - 범례를 쪽 안에 넣는다. 축 너비를 줄여 오른쪽에 범례 자리를 만든다.
   - 범례 오른쪽 끝은 쪽 오른쪽 끝에서 2 mm 이상 안쪽에 둔다. 그림 높이는 234 mm 이하를 지킨다.
3. **Fig. 5a**: 이름과 "n = …" 글자의 위치를 다시 정한다. 지시선이 다른 글자나 다른 점을 가로지르지 않아야 한다.
4. **Fig. 6**
   - c의 x 눈금 글자는 짧게, 가로로 쓴다: "Unmasked", "kNN", "Participant mean". 필요하면 두 줄로 나눈다.
   - c의 눈금 아래에 묶음 이름을 둔다. 2–3번째 눈금 아래에 "Random masking", 4–5번째 눈금 아래에 "Low-expression masking"을 두고, 묶음 이름 위에 가는 괄호 선을 둔다.
   - c에서 같은 x에 있는 세 시계 표식을 옆으로 조금씩 벌린다(−0.12, 0, +0.12).
   - b의 범례 항목 "Nonzero-weight features of the clock"은 그림 안의 세로 막대와 같은 모양(|)으로 그린다.
5. **Fig. 7a와 S2a**
   - y축은 자료 전체 범위를 보인다. 음수를 포함하고, 위아래에 5% 여백을 둔다. y = 0에는 가는 회색 선을 둔다.
   - 글 상자는 선이 지나지 않는 곳에 둔다(예: 왼쪽 아래 음수 영역).
6. **Fig. 7b–d와 S2b–d**
   - 기준선 모양을 바꾼다. 0.05는 가는 회색 실선(`#BFBFBF`), 0.10은 가는 회색 일점쇄선(`-.`, `#808080`)이다. 둘 다 자료 선 아래에 그린다(zorder).
   - 선 끝의 "0.05"와 "0.10" 글자를 지운다. 대신 아래 공통 범례에 두 항목을 더한다: "Nominal α = 0.05", "10% false-positive rate".
7. **Fig. 8a**: x 범주 글자를 b처럼 30도 돌린다.
8. **Fig. 8a와 S3a**
   - 같은 x에서 자료별로 x를 조금씩 벌린다. 자료 순서대로 −0.06, −0.02, +0.02, +0.06이다.
   - 채운 표식을 빈 표식 위에 그린다.
   - 비율 글자의 지시선은 옮긴 점에 맞춘다.
9. **φ̄**: 모든 그림에서 `$\bar{\mathrm{\varphi}}$`로 쓴다(곧은 φ, U+03C6).

## 3. 점검 (방법을 바꾼다)

그림마다 아래 값을 표로 낸다. 모두 0이 목표다. 0이 아닌 것은 그림과 대상별로 적는다.

1. **PDF 잘림**: 저장된 PDF에 `pdftotext -bbox`를 돌린다. 단어 상자가 쪽 경계에서 1 mm 안쪽 선을 넘는 단어 수를 센다.
2. **글자 범위**
   - `fig.canvas.draw()` 뒤 `fig.findobj(matplotlib.text.Text)`로 글자를 모은다. 보이고 비어 있지 않은 모든 글자(눈금, 범례, 주석, 머리글 포함)가 대상이다.
   - 각 글자의 `get_window_extent(renderer)`를 `fig.bbox`와 비교해 밖으로 나간 글자 수를 센다.
   - 검사한 글자 수도 적는다.
3. **글자 겹침**: 2에서 모은 모든 글자 쌍의 상자 겹침 수다. 눈금 글자도 포함한다.
4. **지시선 교차**: 주석 지시선(annotate 화살표)이 다른 글자 상자를 지나는 수다.
5. **축 밖 자료**
   - 각 축에서 선과 점의 자료 가운데 축 범위 밖에 있는 점 수를 센다.
   - 화살표로 일부러 자른 구간(Fig. 3c, 4a, 4b, S1c)은 따로 세어 "의도"로 적는다.
6. 글자 크기, 투명도, 글꼴은 지시서 11 §5의 2–4대로 그대로 점검한다.
7. 검토 묶음 `figures/manuscript/all_figures_review.pdf`와 `figures/submission/` 사본을 다시 만든다.
